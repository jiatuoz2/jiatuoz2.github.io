# Board textures

Textures for the "My Journey" detective boards (`_sass/_journey-board.scss`) and the close-examine view
(`_sass/_journey-examine.scss`). None is downloaded: every file here was made for this site with Python (NumPy +
Pillow) from seeded noise, with no outside artwork, and is dedicated to the public domain
([CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)).

`slate.jpg` (the dark chalky slate of the boards, 512 × 512 seamless tile): periodic filtered noise for the mottling and
chalk wipes, sparse dust specks and faint scratches, tinted blue-grey. The street maps drawn over it are in `../maps/`
(see the CREDITS.md there).

Generated by `bin/build_journey_textures.py` (run it again to rebuild them; the output is the same every run):

| File                                   | What it is                                                                                                                                                                                                                              |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `paper-fibre.jpg`                      | 1024 px seamless greyscale tile multiplied into every paper: pulp mottling, fine fibres, the odd fleck                                                                                                                                  |
| `manila-fibre.jpg`                     | the same for the manila folders: coarser, flecked board fibre                                                                                                                                                                           |
| `crease-<kind>.jpg`, `-sm.jpg`         | fold and handling maps (1600 px for the examine view, 512 px for the board): `trifold`, `half`, `cross`, `corner` (a dog-ear), `wave`, `crumple`; mid grey is flat paper, lit from the top left, used with `mix-blend-mode: hard-light` |
| `crease-plate.jpg`                     | the board's title sheet: buckled between its two strips of tape, flat under them, one soft fold, its free corners lifting                                                                                                               |
| `paper-edge-a.jpg`, `paper-edge-b.jpg` | edge wear and handling grime (near white, multiplied): frayed edges, nicks, thumb marks, a faint vignette                                                                                                                               |
| `tape-crepe.png`                       | crepe and fibre of masking tape (grey + alpha), tiled along a strip over the tape's color                                                                                                                                               |
| `tape-tear-l.png`, `tape-tear-r.png`   | alpha masks of a strip's torn ends                                                                                                                                                                                                      |
| `ink-mottle.png`                       | alpha mask of uneven stamp ink                                                                                                                                                                                                          |
| `print-luster.jpg`                     | the fine pebble of a luster photo print (grey, overlay)                                                                                                                                                                                 |
| `leatherette.jpg`                      | the pebbled grain of a padded diploma cover (grey, overlay)                                                                                                                                                                             |
